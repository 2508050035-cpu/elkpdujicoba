👤 Identitas Siswa

Ringkasan Materi

Buka tiap bagian untuk melihat konsep, rumus, dan animasinya.

1️⃣ Translasi (Pergeseran)

Memindahkan setiap titik sejauh jarak dan arah yang sama. Bentuk & ukuran tidak berubah.

T(a, b): (x, y) → (x + a, y + b)

🪶 Pada batik: motif daun yang diulang berjajar ke kanan atau ke bawah.

2️⃣ Refleksi (Pencerminan)

Memindahkan titik ke seberang garis cermin dengan jarak yang sama.

CerminBayangan (x, y)
Sumbu x(x, −y)
Sumbu y(−x, y)
Garis y = x(y, x)
Garis y = −x(−y, −x)

🪶 Pada batik: motif simetris kiri-kanan seperti sayap atau bunga yang saling berhadapan.

3️⃣ Rotasi (Perputaran)

Memutar titik terhadap pusat sejauh sudut tertentu (positif = berlawanan arah jarum jam).

Rotasi pusat O(0,0)Bayangan (x, y)
90°(−y, x)
180°(−x, −y)
270° (−90°)(y, −x)

🪶 Pada batik: motif kawung/bunga yang menyebar melingkar dari satu titik pusat.

4️⃣ Dilatasi (Perkalian / Perbesaran)

Mengubah ukuran bangun dengan faktor skala k terhadap pusat tertentu. Bentuk tetap sebangun.

Pusat O(0,0): (x, y) → (kx, ky)
Pusat P(p, q): (x, y) → (p + k(x−p), q + k(y−q))

|k| > 1 memperbesar, 0 < |k| < 1 memperkecil, k negatif membalik arah.

🪶 Pada batik: motif bertingkat dari kecil ke besar.

⭐ Sifat Penting

Translasi, refleksi, dan rotasi disebut isometri karena menjaga ukuran dan bentuk (kongruen). Dilatasi menghasilkan bangun sebangun (ukuran berubah).

Lab Geometri (rumus transformasi)

function rotasi(x, y, p, q, deg){
  const t = deg * Math.PI / 180;
  const dx = x - p, dy = y - q;
  return [p + dx*Math.cos(t) - dy*Math.sin(t),
          q + dx*Math.sin(t) + dy*Math.cos(t)];
}
function dilatasi(x, y, p, q, k){
  return [p + k*(x - p), q + k*(y - q)];
}

    
Animasi dibuat dengan interpolasi parameter t dari 0 ke 1 pada rumus-rumus tersebut.
